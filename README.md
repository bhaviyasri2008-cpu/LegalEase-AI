An AI-powered platform to generate legal documents instantly in simple language.

---

### ✨ What is LegalEase-AI?
Normal people ku legal document create panna lawyer venum, kasu adhigam. LegalEase-AI AI vechu 30 seconds la document generate pannum.

### 🚀 Features
- 📝 Generate Rental Agreement, NDA, Offer Letter, Affidavit
- 🤖 AI-Powered & Legally Accurate
- 🌐 Simple English + Tamil Support
- 📄 Download as PDF / DOCX
- 🔒 100% Secure & Private

### 🛠️ Tech Stack
- *Frontend:* HTML, CSS, JS / React
- *Backend:* Python Flask
- *AI:* OpenAI API
- *Database:* Firebase (Upcoming)
